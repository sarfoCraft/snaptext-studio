CLOUDFLARE PAGES DEPLOYMENT

This file is a quick reminder. Follow DEPLOYMENT-CHECKLIST.txt for the full process.

1. Back up the current GitHub production branch.
2. Create a separate test branch.
3. Extract the updated ZIP.
4. Copy the ZIP contents into the repository root, preserving folders.
5. Commit and push the test branch.
6. Open the Cloudflare Pages preview deployment.
7. Test tools, redirects, ads, sitemap, privacy pages and mobile layout.
8. Merge into the production branch only after testing.

Do not upload the ZIP itself as a nested folder.
Do not deploy to production before preview testing.
