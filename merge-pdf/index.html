Merge PDF files with an online PDF combiner

Use this free online PDF combiner to merge PDF files into one document. Select 2 to 20 PDFs, each no larger than 50 MB, and keep them in the order you want. This PDF merger combines existing PDF documents; it does not convert image files. To combine JPG or PNG pictures into a PDF, use the Images to PDF tool.

How to merge PDF files online

  1. Click Choose PDFs and select at least two PDF files.
  2. Select the files in the order you want them combined, or arrange the selection order before starting.
  3. Click Merge files.
  4. Download the combined PDF and check the page sequence.

Before merging

Make sure each file opens correctly and is not damaged or password-protected in a way that prevents processing. If the combined file is large, consider whether you need every page. You can use Split PDF to keep selected pages from a document.

Frequently asked questions

How many PDFs can I merge?

You can select up to 20 PDF files in one session. Each file must be 50 MB or smaller. Processing time depends on file size, page count and your device.

Will merging reduce PDF quality?

Merging combines pages; it is not intended as an image-compression step. Always review the downloaded file to confirm the result.

How do I combine PDF files for free?

Select at least two PDF files, keep them in the order you want, and choose Merge files. The tool can merge up to 20 PDFs in one session. Review the combined document before sharing it.
