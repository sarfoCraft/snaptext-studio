Create a QR code from a URL or text

WordToPDF's QR Code Generator turns a website address, short message, email address or other text into a scannable QR code. Choose a size, generate the code and download it as a PNG image.

How to generate a QR code

  1. Enter the full URL or text you want the QR code to contain.
  2. Choose the output size.
  3. Select Generate QR code.
  4. Scan the result with a phone before printing or sharing it.
  5. Download the PNG file.

QR code testing tips

Use a short, correct URL and test the generated code on more than one device if it will be printed. Leave enough blank space around the code, avoid stretching it and make sure the final print is large enough for the intended scanning distance.

Frequently asked questions

Can I create a QR code for a website?

Yes. Enter the complete website URL, including the https:// prefix when appropriate, then generate the code.

Can I download the QR code?

Yes. The generated QR code can be downloaded as a PNG image.
