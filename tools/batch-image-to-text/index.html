    Batch OCR is useful when you have several screenshots, scanned notes or document photographs that need to become editable text. Select all images at once and let the browser process them sequentially.

    How to use Batch Image to Text

    1. Select multiple screenshots or document images.
    2. Choose the language used in the images.
    3. Click Extract all text and follow the progress messages.
    4. Review the combined result and download the TXT file.

    Make repeated transcription tasks easier

    Batch OCR can reduce repetitive copying when documents are already available as images. Each result is separated by its original filename, making it easier to see which text came from each source.

    OCR is not perfect. Proofread names, numbers, addresses and punctuation, particularly when the source is blurry, skewed or low contrast.

    Choosing a recognition language

    Selecting the correct language helps the OCR engine recognize letter shapes. Mixed-language images may require an appropriate combined language option when available.

    Frequently asked questions

    Will my image results be kept separate?

    The combined text includes a filename heading before the text from each image.

    Can I edit the OCR output?

    Yes. You can review and edit the combined result before downloading it as TXT.
