Image to Text uses optical character recognition (OCR) to recognize printed words in a screenshot, photo or scan. Upload an image, choose a language, extract text and correct the result directly in the editor.

How to use Image to Text (OCR)

  1. Upload or paste a screenshot, photograph or scan.
  2. Choose the recognition language and optional image enhancement.
  3. Click Extract text from image.
  4. Edit the result, then copy it, download TXT or print to PDF.

What is image to text OCR?

Optical character recognition converts images of letters into machine-readable text. It is useful when you want to quote text from a screenshot, archive notes or reuse a paragraph from a photographed document.

Quality varies with resolution, contrast, lighting, font and language. Always proofread important names, dates and figures before sharing or using them.

Get clearer OCR results

Choose a sharp source image and crop irrelevant borders. Make sure text is upright and not obscured by glare. Select the correct language, and try the image enhancement option if the source has poor contrast.

Frequently asked questions

Can I edit the text after OCR?

Yes. The extracted text appears in a fully editable text area.

Can I save the extracted text as PDF?

Yes. Use the export control to open the print dialog and choose Save as PDF.

Does it support more than English?

Yes. The current language selector includes Urdu, Arabic, Hindi, Spanish, French and German, among others.
