How to Extract Text from an Image with OCR

OCR can turn words in a screenshot, photo or scanned page into text you can edit. The result still needs proofreading, especially when the image contains small print, numbers or several columns.

WordToPDF Guides · Updated November 28, 2026

Open Image to Text ↗

Start with a clear image

OCR works from the pixels in an image, so the quality of the source matters. Use a sharp image with readable text, good contrast and as little glare as possible. Keep the page upright and avoid strong camera angles. If the image includes a desk or other background, crop it so the text takes up more of the frame.

WordToPDF's single-image OCR tool accepts image files up to 20 MB. The page lists PNG, JPG, WebP and BMP as common formats. If a photo is larger than the limit, make a smaller copy and keep the original unchanged.

Choose the language that matches the image

Open the Image to Text tool and select the language used in the image before running OCR. The current language menu includes English, English + Urdu, Urdu, Arabic, Hindi, Spanish, French and German.

Choose the closest match to the text you want to recognise. If the image contains both English and Urdu, use the combined English + Urdu option. A language mismatch can cause the OCR engine to substitute characters or miss words.

Extract text with WordToPDF

  1. Open Image to Text.
  2. Upload an image, paste an image from your clipboard or use the screen-capture option.
  3. Choose the recognition language.
  4. Leave Improve image for better results enabled if you want the built-in grayscale and contrast adjustment. You can switch it off if the adjusted version makes the text harder to read.
  5. Select Extract text from image and wait for recognition to finish.
  6. Review the result in the editable text area before copying or downloading it.

The enhancement option applies a light contrast adjustment and can scale very large images down before OCR. It cannot recover details that are missing from a blurry or low-resolution source.

Review and export the extracted text

Compare the result with the original image. Pay special attention to names, addresses, dates, invoice numbers, totals, decimal points and punctuation. OCR can confuse characters that look alike, such as the letter O and the number 0.

You can edit the extracted text, use Clean to tidy spacing, copy it, or download it as a TXT file. The Export PDF option opens your browser's print window. Choose Save as PDF there if you want a PDF copy of the recognised text.

The PDF export is a print-ready text document, not a reconstruction of the original image's exact layout. Keep the original image if you need to check formatting or verify the source.

A practical example: reading a receipt

Imagine you need to copy details from a photographed receipt into a spreadsheet. OCR can help extract the store name, date, item descriptions and amounts, but those are also the details most worth checking. A faint decimal point can change a price, and a blurred digit can change an order or reference number.

After extraction, compare each amount with the receipt and correct any line that does not match. Treat the OCR result as a first draft of the text, not as a verified record.

What affects OCR accuracy?

  • Focus and resolution: small or blurred letters are difficult to distinguish.
  • Lighting: glare, shadows and low contrast hide parts of characters.
  • Page angle: a slanted or curved page can make lines harder to read.
  • Typography: decorative fonts, handwriting, stamps and unusual symbols can reduce recognition quality.
  • Layout: columns, tables and text close together may be read in an unexpected order.
  • Language: selecting the wrong recognition language can produce incorrect characters.

The confidence figure shown by the tool is an OCR engine estimate, not a guarantee that every word is correct. Proofread important content against the original.

Extract text from several images at once

If you have multiple screenshots or photos, use Batch OCR. Select the images, choose a recognition language and start the process. The tool reads the selected images one at a time and places each result under its filename in one combined text area. You can then download the combined result as a TXT file.

Large batches can take longer because each image is processed in sequence. Check the output for every file before using it, and split a very large batch if your browser or device struggles.

Frequently asked questions

Can OCR extract text from handwriting?

Handwriting recognition is less reliable than printed text. The current WordToPDF workflow is best suited to readable printed text, and handwritten words may be missed or misread.

Does OCR keep the original page layout?

No. The tool extracts editable text into a text area. It does not reproduce the original page design, columns, tables or exact spacing.

Can I save the extracted text as a PDF?

Yes. Select Export PDF, then choose Save as PDF in your browser's print window.

Why did OCR return incorrect numbers?

Small print, blur, glare and similar-looking characters can cause mistakes. Enlarge or recapture the image if possible, choose the right language and compare all important numbers with the source.
