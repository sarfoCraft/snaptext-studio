Start with the right image

Use a clear, well-lit image where letters are large enough to read. Crop background distractions and avoid heavy perspective distortion before scanning.

Choose language and run OCR

Open Image to Text, upload the file and select a recognition language. After the scan, compare the extracted text with the original image and correct names, dates and punctuation.

Choose how to save your result

Copy text for immediate use, download TXT for a lightweight file, or use the browser print flow to save a PDF. Keep the original image when accuracy matters.
