How to Save an Email as a PDF

Use your email app's print option to save a message as a PDF. These steps cover Gmail, Outlook on the web and desktop email workflows.

WordToPDF Guides · Published November 28, 2026 · Updated November 28, 2026

Open Merge PDF ↗

Save an email as a PDF in Gmail

  1. Open Gmail and open the email message you want to save.
  2. Choose the message's Print option. Depending on the layout, it may appear as a printer icon or in the More menu.
  3. When the browser print dialog opens, choose Save as PDF as the destination.
  4. Review the page preview, choose the pages you need and save the file to your device.

Open the saved PDF once to make sure the sender, date, subject and message body are readable. If the email contains a long thread, check whether the print view includes the messages you intended to keep.

Save an Outlook email as a PDF

Outlook on the web

Open the email in Outlook on the web, use the message's More actions or Print option, then choose Save as PDF in the browser print dialog. Menu names may vary as Microsoft updates Outlook's interface.

Outlook desktop

Open the message and choose Print. On Windows, select Microsoft Print to PDF if it is available. On macOS, use the PDF option in the system print dialog and save the file. Check the preview before saving.

What happens to email attachments?

Printing an email usually saves the message's print view. Attachments may not be included as full, separate files in the resulting PDF. If you need to keep an attachment, download it separately and save or convert it using the appropriate workflow.

If you save several email messages as separate PDFs and want one document, use Merge PDF. Select the files in the order you want them to appear, then download and review the combined PDF.

Check the PDF before sharing it

Review the recipient names, sender, date, subject, message body and page breaks. Remove unrelated messages from a long thread before printing if your email app allows it. Be careful with private information and attachments, especially when saving work or financial correspondence.

Frequently asked questions about saving email as PDF

How do I save an email as a PDF?

Open the email, choose Print and select Save as PDF in the print dialog. The exact menu labels depend on your email app and device.

How do I save an Outlook email as a PDF?

Open the message in Outlook, choose Print and use the system or browser print destination to save it as a PDF.

Can I save multiple emails in one PDF?

You can print messages individually and then combine the resulting PDF files with WordToPDF Merge PDF. Check the page order before sharing the combined file.

Are attachments included in the saved email PDF?

Not always. The print view may include attachment names or previews without embedding the original files. Download important attachments separately and keep them with the PDF.
