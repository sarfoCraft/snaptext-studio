How to Combine Multiple Images into One PDF

Put photos, screenshots, receipts or scanned pages into one PDF. This guide explains the current WordToPDF workflow, page layout and a few checks to make before you share the file.

WordToPDF Guides · Updated November 28, 2026

Open Images to PDF ↗

Prepare the images before you upload

Start by collecting only the images that belong in the document. Open each file and check that it shows the right page, is readable and is facing the correct direction. If a photo includes a large desk, background or empty border, crop it before converting so the page is focused on the information.

For a document made from phone photos, use even lighting and hold the camera as parallel to the page as you can. Glare, shadows and perspective distortion can make small print harder to read, even when the PDF itself is created successfully.

If the images are in different formats, use files your browser can display. The tool accepts image files; JPG and PNG are handled directly, while other formats are decoded by the browser before being added to the PDF.

Check the page order first

The order of the images becomes the order of the PDF pages. Before you start, decide which page should come first, then select the files in that sequence. The current tool builds the PDF using the order supplied by the browser. It does not provide a separate drag-and-drop page-reordering control after selection.

For example, if you are combining three pages of class notes, select page 1, page 2 and page 3 in that order. After the file downloads, open it and confirm that the pages appear as expected. This quick check is worth doing before sending the document to someone else.

Combine the images with WordToPDF

  1. Open the Images to PDF tool.
  2. Select Choose images and add the image files you want to include.
  3. Check that you selected the pages in the intended order.
  4. Select Create PDF and wait while the browser builds the document.
  5. Download the PDF, open it and review every page before sharing it.

The conversion runs in the browser. If you select a large number of high-resolution images, your device may need more memory and the process may take longer. If the browser struggles, try a smaller group of files.

How the PDF pages are laid out

The current tool creates A4 pages. Each image is scaled to fit inside the page margins, keeps its proportions and is placed in the centre. The tool does not stretch a portrait image to fill a landscape shape or crop it to the page edges. Depending on the image shape, you may see unused white space around it.

This matters when mixing portrait scans with wide screenshots. The result can still be one consistent A4 PDF, but the amount of white space will vary from page to page. If the page shape is important, crop or prepare the images before combining them.

Will the text in the PDF be searchable?

No. This workflow places each image on a PDF page. It does not add an OCR text layer, so words inside a photo or scan will not automatically become selectable or searchable.

If you need to copy words from an image, run it through Image to Text OCR separately and review the extracted text. That OCR workflow produces editable text, but it does not turn the image-to-PDF output into a searchable PDF.

File sizes and common problems

The current tool accepts up to 50 images in one batch, with a maximum file size of 20 MB per image. Large images and large batches can still use substantial browser memory. If conversion fails or the tab becomes unresponsive, try a smaller batch or use smaller copies of the images.

  • A page looks blurry: go back to the original image and use a sharper, higher-resolution copy.
  • A page is sideways: rotate the image before uploading it.
  • The page has wide white borders: crop the original image more tightly before conversion.
  • The text cannot be selected: that is expected for image-based pages. Use OCR if you need editable text.
  • The PDF is larger than expected: high-resolution images can create a large output. Resize copies when the original resolution is more than you need, but keep the originals.

Frequently asked questions

Which image formats can I combine?

The file picker accepts image files. JPG and PNG are embedded directly. Other formats must be readable by your browser so the tool can decode them and convert them for the PDF. Common formats include JPG, PNG, WebP and BMP.

Can I combine PDF files with images in this tool?

No. This page creates a PDF from images. To join existing PDF documents, use the Merge PDF tool.

Can I select text from the PDF after conversion?

Not from the image pages created by this tool. The page content is stored as images. Use OCR separately if you need text you can copy or edit.

Does the tool keep the original image dimensions?

It keeps the image proportions but fits each image onto an A4 page. The image may be scaled down and may have white space around it.
