How to Convert a Photo to PDF on iPhone

Follow a practical phone workflow for saving a photo, opening WordToPDF in your mobile browser and creating a PDF from one or more images.

WordToPDF Guides · Published November 28, 2026 · Updated November 28, 2026

Open Images to PDF ↗

Save the photo so your browser can select it

On an iPhone, open Photos, select the picture and use the Share menu to save a copy to Files if you want to choose it from the browser's file picker. You can also select images directly from the picker when your iOS version and browser offer that option.

On Android, make sure the photo is available in your Gallery, Photos app or a folder that Chrome can access. If the image is stored in a cloud app, download a local copy first when the file picker cannot select it directly.

Convert a photo to PDF on iPhone with Safari

  1. Open Safari and visit the WordToPDF Images to PDF tool.
  2. Tap Choose images and select the photo from Photos or Files.
  3. If you want several pictures in one PDF, select them in the order you want the pages to appear.
  4. Choose Create PDF, wait for processing and download the result.
  5. Open the PDF from your downloads or Files and check the page order and readability.

The file picker can look different across iOS versions. If Photos are not shown as a source, save the pictures to Files first and select them there.

Convert pictures to PDF on Android

Open Chrome on your Android phone and visit Images to PDF. Tap Choose images, browse to the folder containing your photos or screenshots, select the files and choose Create PDF. Review the downloaded PDF in your device's file viewer before sharing it.

This is an image-to-PDF workflow. It does not turn every file type on your phone into a PDF. For a DOCX Word document, use Word to PDF. That tool prepares a print-ready view and opens the browser's print dialog; the save-as-PDF step depends on your device and browser.

Create one PDF from multiple mobile photos

WordToPDF Images to PDF accepts JPG, JPEG, PNG, WebP and BMP images. You can select up to 50 images in one batch, with a maximum of 20 MB per image. Each image becomes an A4 page and is scaled to fit while keeping its proportions.

Choose the images in the intended page order. The tool does not provide a separate drag-and-drop page-reordering control after selection. If you need to change the order, select the files again in the right sequence.

Frequently asked questions about mobile PDF conversion

How do I convert a picture to PDF on iPhone?

Open Images to PDF in Safari, choose the picture from Photos or Files, select Create PDF and save the downloaded file. If the photo is not available in the picker, save a copy to Files first.

Can I convert a screenshot to PDF on my phone?

Yes. Save the screenshot as an image, select it in Images to PDF and create the PDF. You can include other supported images in the same document.

How do I convert files to PDF using a mobile phone?

The workflow depends on the file type. Use Images to PDF for supported image files and Word to PDF for DOCX documents. The Word tool uses the browser print dialog, so review the mobile print options before saving.

Can I combine more than one photo?

Yes. Select multiple supported images, up to 50 files per batch and 20 MB per image. Check their order before creating the PDF.
