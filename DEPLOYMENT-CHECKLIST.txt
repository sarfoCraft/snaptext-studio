WORDTOPDF DEPLOYMENT CHECKLIST

GITHUB PAGES (current setup)
[ ] Extract the ZIP.
[ ] Upload the ZIP contents to the root of sarfocraft/snaptext-studio.
[ ] In GitHub Settings > Pages, select Deploy from a branch.
[ ] Select branch main and folder / (root).
[ ] Wait for the deployment workflow to finish.
[ ] Open https://sarfocraft.github.io/snaptext-studio/ and hard-refresh.
[ ] Test the homepage, every current tool, legacy /tools/ links, articles and mobile layout.
[ ] If using wordtopdf.fun, add it in Settings > Pages > Custom domain.
[ ] Set Cloudflare DNS records to the exact values GitHub Pages provides.
[ ] Confirm HTTPS and redirects work.

CLOUDFLARE PAGES (alternative hosting)
[ ] Connect the GitHub repository to Cloudflare Pages.
[ ] Framework preset: None.
[ ] Build command: leave blank.
[ ] Build output directory: .
[ ] Deploy and add wordtopdf.fun under Custom domains.
[ ] Test all pages and tools over HTTPS.

BEFORE PUBLIC LAUNCH
[ ] Replace contact/support email placeholders.
[ ] Review Privacy Policy and Terms against actual services and target visitors.
[ ] Test every converter with sample files on desktop and mobile.
[ ] Submit https://wordtopdf.fun/sitemap.xml to Google Search Console.

AD MONETIZATION
[ ] Apply to Adsterra and submit wordtopdf.fun for review.
[ ] Create the approved banner zone and paste the exact generated tag.
[ ] Add and verify wordtopdf.fun in Monetag.
[ ] Create the chosen on-page banner zone and paste the exact generated tag.
[ ] Add exact seller records to ads.txt only when supplied by the ad networks.
[ ] Review privacy and consent requirements for your visitors.
[ ] Test the website with ad blockers disabled on desktop and mobile.

NOTES
- This is a static browser-side website. It does not include WordPress, PHP, MySQL,
  accounts, payments, server-side conversion or file storage.
- No publisher tags, zone IDs, seller IDs or account credentials are included.
- Read ADS-SETUP-GUIDE.md before installing advertising tags.
